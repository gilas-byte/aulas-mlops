## 🤖 What is MLOps?

MLOps is DevOps for artificial intelligence, combining automation and collaboration to build, deploy, and monitor machine learning models safely and reliably in the real world.

**`DevOps is a culture and practice that unites software development and IT operations to build, test, and release code faster and more reliably through automation.`**

## 🤖 O que é MLOps?

MLOps é o DevOps para inteligência artificial, combinando automação e colaboração para construir, implantar e monitorar modelos de machine learning de forma segura e confiável no mundo real.

**`DevOps é uma cultura e prática que une o desenvolvimento de software e as operações de TI para criar, testar e liberar código de forma mais rápida e confiável por meio da automação.`**
